BizzTalks website - deployment package
=======================================

Contents
  index.html            The website (one page)
  404.html              Page shown for broken links
  assets/img/           Portfolio carousels, founder photo, certificates
  assets/logo/          BizzTalks logo, favicon and app icons
  robots.txt, sitemap.xml, site.webmanifest   Search engine and app files

Upload the CONTENTS of this folder (not the folder itself) to your site root.

Vercel:   vercel.com > Add New > Project > drag this folder in > Deploy.
Netlify:  app.netlify.com/drop > drag this folder in.
Hostinger / cPanel:  File Manager > public_html > upload the zip > Extract.
GitHub Pages:  push the files to a repo > Settings > Pages > deploy from main.

Then connect the domain bizztalks.in in your host's Domains settings.

Before going live, check:
  - "Aug-Oct 2026" in the Results section is the right year.
  - The "BizzTalks website" project links to https://www.bizztalks.in
